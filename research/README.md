# Open-Source AI System Research Pack

This directory records verified upstream repository pointers and the planned system composition. It is designed to augment the existing GSC Studio/pranuAgent project without overwriting its current files.

See:
- `REPOSITORIES.md` — repositories to clone
- `SYSTEM-DESIGN.md` — integration dashboard design
- `SETUP-AND-COMMANDS.md` — PowerShell and Bash commands
- `PLUGINS-AND-SKILLS.md` — plugin, API, MCP, skill, and connector registry

Research uses Firecrawl's developer index plus the authenticated GitHub repository metadata connector. General Firecrawl search was rate-limited during this run, so this is a verified starting set, not an exhaustive search of all GitHub projects.
