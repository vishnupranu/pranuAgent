# 23 — Release Gates

This file lists required release gates; an unchecked item is not complete.

- [ ] Actual product behavior matches requirements and README.
- [ ] CI lint, types, tests and production build pass.
- [ ] Local Ollama generation and tool workflow verified.
- [ ] Project file changes are safe, reviewable and reversible.
- [ ] Browser preview is real, isolated and stoppable.
- [ ] PowerShell and macOS shell adapters are tested.
- [ ] Agent tasks are persistent, cancellable and bounded.
- [ ] Plugins/skills have permission review and audit trails.
- [ ] Secrets, paths, network requests and remote writes are secured.
- [ ] Windows x64 package tested on clean Windows.
- [ ] Intel macOS package tested on clean Intel Mac.
- [ ] Vercel preview is verified.
- [ ] Domain pranu.ux.ui.dev DNS and HTTPS verified before claiming deployment.
- [ ] Known limitations, rollback steps and third-party notices documented.
