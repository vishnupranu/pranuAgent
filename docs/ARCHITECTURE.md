# PRANU.AGENT Architecture

PRANU.AGENT is a universal AI design craft platform centered on conversational intent, specialist agent composition, provider-agnostic model routing, artifact generation, and multi-platform export.

## Layers

1. Natural language design engine parses intent and constraints.
2. Agent orchestrator composes UX, UI, accessibility, engineering, CAD, content, QA, workflow, and documentation specialists.
3. Provider adapters route tasks across OpenAI, Anthropic, Gemini, Mistral, Grok, DeepSeek, OpenRouter, Ollama, and local models.
4. Design system engine emits tokens, components, accessibility rules, and cross-platform exports.
5. Product surfaces include web, browser extension, Electron desktop, mobile support, design plugins, Adobe bridge, and CAD bridge.
